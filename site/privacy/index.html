Privacy record

Policy / effective 28 August 2026

Keep your file list private.

The browser sample checks data in your browser. The command-line tool reads files you choose.

Browser demo

The demo processes file-list text and selected file details in your browser. It does not upload that data. Demo-only state uses the demo: browser storage prefix and is removed when you leave the demo.

This site has no accounts, analytics, ads, third-party fonts, or third-party runtime scripts.

Command-line tool

The command-line tool has no network client and sends no usage data. It reads the file list and local folder you name. It does not follow symlinks.

Saved reports

Reports written with --output are encrypted locally. They need the passphrase supplied through CEE_PASSPHRASE to decrypt.
