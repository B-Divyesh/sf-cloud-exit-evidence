Privacy record

Policy / effective 28 August 2026

Keep your file list private.

The browser sample checks data in your browser. The command-line tool reads files you choose.

Browser demo

The demo processes file-list text and selected file details in your browser. It does not upload that data. Demo-only state uses the demo: browser storage prefix and is removed when you leave the demo.

This site has no accounts, analytics, ads, third-party fonts, or third-party runtime scripts.

Command-line tool

The CLI makes no network requests or telemetry. It reads the file list and local folder you name. It does not follow symlinks.

Saved reports

Reports written with --output are encrypted locally. The CLI uses XChaCha20-Poly1305 with an Argon2id-derived key. Your passphrase comes from CEE_PASSPHRASE and is not stored.

Hosting logs

The host may keep short security and request logs. This project does not receive or enrich them. Use the public source repository for questions.
