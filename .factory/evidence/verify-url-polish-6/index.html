§ 02 / How it works

Compare files in three steps.

  1. 01

    Read your file list

    Use JSON, CSV, or an rclone JSON file list. Unsafe and duplicate paths are rejected.

  2. 02

    Read your drive

    Check the selected folder without following links. Compare names, sizes, dates, and supplied hashes.

  3. 03

    Show what needs work

    See missing, old, changed, and excluded files. Record accepted exclusions in the command-line report.

§ 03 / Limits

What this check does not do.

It does not copy or restore files.

The browser demo checks only bundled sample files in this tab.

Keep versioned media. Test real restores.
