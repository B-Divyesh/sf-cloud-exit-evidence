# Changelog

All notable changes follow Keep a Changelog. This project uses semantic versioning.

## [0.1.0] - 2026-08-28

### Added

- Local JSON, CSV, and rclone manifest audits.
- Missing, stale, size/hash mismatch, extra, unsafe, and excluded-path evidence.
- Folder, file type, and month coverage summaries.
- Terminal, JSON, and Markdown reports with scriptable exit codes.
- Argon2id/XChaCha20-Poly1305 encrypted report files.
- Privacy-first documentation site and browser-only interactive demo.
